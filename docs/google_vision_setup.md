# Google Cloud Vision API 키 발급 가이드

이 문서는 Handwriting OCR MCP 서버에서 사용할 Google Cloud Vision API 키를 발급받고 설정하는 방법을 안내합니다.

## 1. Google Cloud 프로젝트 생성

1. [Google Cloud Console](https://console.cloud.google.com/)에 접속합니다.
2. 상단 네비게이션 바에서 프로젝트 선택 드롭다운을 클릭합니다.
3. **새 프로젝트**를 클릭합니다.
4. 프로젝트 이름을 입력하고 **만들기**를 클릭합니다.

## 2. 결제 계정 연결 (필수)

Google Cloud Vision API를 사용하려면 결제 계정이 연결되어 있어야 합니다. (무료 등급 내에서 사용 가능)

1. 좌측 메뉴에서 **결제**로 이동합니다.
2. **결제 계정 연결**을 클릭하고 안내에 따라 결제 정보를 등록합니다.

## 3. Vision API 활성화

1. 상단 검색창에 "Cloud Vision API"를 입력하고 선택합니다.
2. **사용** 버튼을 클릭하여 API를 활성화합니다.


## 4. 서비스 계정 키 생성

1. 좌측 메뉴에서 **API 및 서비스** > **사용자 인증 정보**로 이동합니다.
2. 상단의 **+ 사용자 인증 정보 만들기**를 클릭하고 **서비스 계정**을 선택합니다.
3. 서비스 계정 세부정보를 입력하고 **만들기 및 계속**을 클릭합니다.
4. (선택사항) 역할 선택에서 **Cloud Vision API 사용자** 등의 적절한 역할을 부여합니다.
5. **완료**를 클릭하여 서비스 계정을 생성합니다.
6. 생성된 서비스 계정을 클릭하고 **키** 탭으로 이동합니다.
7. **키 추가** > **새 키 만들기**를 클릭하고 **JSON**을 선택합니다.
8. 다운로드된 JSON 파일을 안전한 곳에 저장합니다. (예: 프로젝트 루트 외부 또는 `.gitignore`에 추가된 경로)

## 5. 프로젝트 설정

프로젝트 루트 디렉토리의 `.env` 파일에 발급받은 키 파일 경로를 입력합니다.

1. `.env.example` 파일을 복사하여 `.env` 파일을 생성합니다. (이미 존재하면 생략)
   ```bash
   cp .env.example .env
   ```
2. `.env` 파일을 열고 `GOOGLE_APPLICATION_CREDENTIALS` 항목에 JSON 키 파일의 **절대 경로**를 입력합니다.
   ```
   GOOGLE_APPLICATION_CREDENTIALS="/Users/username/keys/my-project-key.json"
   ```

## 6. 확인

설정이 올바르게 되었는지 확인하려면 MCP 서버를 다시 시작하거나, 설치 스크립트의 테스트 기능을 활용할 수 있습니다.

API 키가 유효하지 않거나 할당량이 초과된 경우, 서버는 자동으로 Tesseract OCR(설치된 경우)로 전환하여 작동합니다.
